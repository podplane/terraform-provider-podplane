# Podplane OpenTofu/Terraform Provider

The Podplane OpenTofu/Terraform Provider supplies VM userdata and cluster bootstrap resources for OpenTofu/Terraform configurations generated by the Podplane CLI. It is a standalone binary; runners do not need the CLI installed.

This repository publishes provider binaries, registry documentation, the registry manifest, and signing public key. Source code, tests, and release automation live in [podplane/podplane](https://github.com/podplane/podplane).

- [Provider documentation](https://github.com/podplane/podplane/blob/main/cmd/terraform-provider-podplane/docs.md)
- [Release and version mapping](https://github.com/podplane/podplane/blob/main/cmd/terraform-provider-podplane/docs.md#releases)
- [Published binaries](https://github.com/podplane/terraform-provider-podplane/releases)

For development, clone `podplane/podplane`, run `make build`, and set `PODPLANE_TF_PROVIDER_DIR` to that checkout's absolute `bin` path when running its CLI. Submit issues and code changes there.

Each Podplane release builds both binaries from one commit and publishes the provider first. `release-metadata.json` identifies the source commit and version. Provider versions use a calculated offset until Podplane 2.0.0 to avoid collisions with existing immutable provider releases.
